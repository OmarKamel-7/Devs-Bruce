A Board for Bruce firmware that has everything and easy to be assembled

(Gerber, bom, pick&place, source files are all included in the repo)

## why I made this
i made this because i wanted a bruce board portable every where to test the rf and the some other stuff mainly the subghz and the nfc 
my board made it more portable and just it has what i needed

## How I made this:
Just Added the main modules as they are , the two 5.1k resistors for the type c to the type connector

external antenna for the subghz module the cc1101 , some decoupling caps

a reset button and some silkscreen and all is done for now , I will order it semi assembled excluding the cc1101 and pn532,
screen, nrf , ir just the caps and the esp32 and the type c



## what does the new submission have ?

-antenna trace

-the second jlc pcb image removed

-frimware added

-links added inside the bom file

## note:

the firmware does not belong to me i can only add the bin file for the firmware that will be used

i cant edit to the bom file to be as the jlcpcb site format I have added an external site that has the the parts (local supplier)
